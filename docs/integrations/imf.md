# IMF World Economic Outlook

Atlas Global imports selected annual macroeconomic measures directly from the International Monetary Fund's DataMapper API. These are source-specific IMF series, separate from World Bank definitions. Public queries, rankings, historical charts, comparisons, and CSV exports read persisted PostgreSQL data; they do not contact the IMF.

## Official references and endpoints

- [DataMapper API documentation](https://www.imf.org/external/datamapper/api/), which identifies **v2** as the current version.
- [World Economic Outlook dataset](https://www.imf.org/external/datamapper/datasets/WEO), including the methodology and limitations of historical values and projections.
- [IMF data copyright and usage](https://www.imf.org/external/terms.htm).

The adapter uses the fixed base URL `https://www.imf.org/external/datamapper/api/v2/`. No API key or additional credential is required. Visitor input cannot select another upstream URL.

The following requests were verified against real responses on 2026-11-10:

```text
GET /indicators
GET /countries
GET /GGXWDG_NGDP/BRA/USA/CHN/TWN?periods=2023,2024,2025,2026,2027
GET /BCA_NGDPD?periods=2024,2025,2026
```

The API returned extra countries and years despite requested filters. The production adapter requests one indicator at a time with the documented comma-separated `periods` parameter, then applies the configured country and year bounds locally. Region and analytical-group aggregates are excluded through the official country catalog. Future years beyond the configured end year are not persisted.

## Selected definitions

| Internal indicator | Original IMF code | Unit and frequency |
| --- | --- | --- |
| `IMF.GOVERNMENT.DEBT.GDP` | `GGXWDG_NGDP` — General government gross debt | Percent of GDP; annual. |
| `IMF.CURRENT.ACCOUNT.GDP` | `BCA_NGDPD` — Current account balance, percent of GDP | Percent of GDP; annual. |

Both use internal unit `PERCENT_GDP`. Gross debt covers liabilities requiring future interest and/or principal payments, according to the source definition; valuation and government-sector coverage can vary between countries. It is not household debt, central-government debt alone, or a universal measure of net debt. The current account covers international transactions in goods, services, income, and current transfers; deficits retain their negative values.

The series retains its original name, definition, source organization, WEO edition, and projection boundary. Each release receives its own dataset identity, such as `WEO:2026-10` for **World Economic Outlook (October 2026)**. Importing a different edition creates a separate series rather than silently overwriting a previous edition under the same identity.

## Historical values and projections

The v2 response includes indicator metadata alongside `values`, including `dataset`, `unit`, `source`, and `projection-year`. The adapter validates these fields and requires the embedded metadata to match the catalog fetched during the same execution. A missing or incompatible definition, unit, edition, projection boundary, or API version fails the import.

The native `projection-year` determines the observation flag:

| `providerStatus` | Meaning |
| --- | --- |
| `IMF_HISTORICAL` | Reference year before the provider's projection boundary. Historical WEO values can include IMF staff estimates and adjustments for structural breaks; this flag does not assert final observed data. |
| `IMF_PROJECTION` | Reference year at or after the provider's published projection boundary. This is an official IMF projection, not an estimate generated by Atlas Global. |

The checked October 2026 response identifies 2026 as the first projection year. The implementation reads this boundary from each response; it does not hardcode 2026 or infer actuals from the current calendar year. The default import ends in the current UTC year, so current-year IMF projections can appear with an explicit projection label. No following-year forecast is imported merely because it appears in the upstream response.

UI labels and provenance distinguish these records throughout historical exploration and comparison. CSV retains the original flag in `provider_status`. Sharing a definition and reference year permits careful exploration, but does not remove country-specific fiscal coverage, historical estimation, or accounting differences.

## Country coverage and normalization

Configured Atlas country codes are matched against the official IMF country catalog. Taiwan uses the IMF's native `TWN` code. Kosovo's IMF code `UVK` maps to the existing Atlas/World Bank catalog code `XKX`. The adapter imports observations without replacing the existing localized country names or inferring demographic metadata.

Missing country coverage, omitted series, and absent years do not create observations. An upstream numeric zero remains available; negative current-account balances retain their sign. An explicit upstream null becomes a missing observation while preserving its historical/projection flag. JSON numeric values use decimal arithmetic without binary floating-point conversion, unit scaling, gap filling, or interpolation.

The native `last-modified` field describes indicator metadata maintenance. It is not validated as the revision date of every statistical observation, so `sourceUpdatedAt` remains null. Collection time is stored independently in `importedAt`; the edition identifies the publication context.

## Operational import

Import the country catalog first, then run:

```bash
docker compose run --rm --no-deps backend \
  --spring.main.web-application-type=none \
  --atlas.imf-import.run-once=true
```

The command uses the shared `atlas.import.countries`, `atlas.import.from-year`, and `atlas.import.to-year` settings. The default country scope is the 24 home-selection codes available from WDI; Taiwan can be requested explicitly for this IMF command:

```bash
docker compose run --rm --no-deps backend \
  --spring.main.web-application-type=none \
  --atlas.imf-import.run-once=true \
  --atlas.import.countries=BRA,USA,TWN \
  --atlas.import.from-year=2020 \
  --atlas.import.to-year=2026
```

The fixed years above illustrate a bounded import, not fixed data values. Countries must already exist in the persisted catalog. Run one provider command per process; one-shot commands suppress scheduled jobs. There is no public import endpoint.

The optional additional-source scheduler can refresh the most recent six calendar years within the configured interval. Enable `ADDITIONAL_SOURCES_SCHEDULE_ENABLED=true`; its default schedule is `ADDITIONAL_SOURCES_IMPORT_CRON=0 0 5 * * SAT`, evaluated at 05:00 UTC on Saturdays. Use the full command periodically to reconcile older historical periods and populate a newly published WEO edition's complete history.

The shared annual coordinator obtains an IMF-specific PostgreSQL advisory lock, records the execution, validates normalized records, and persists transactional upserts. Repeating the same release updates existing country/series/year keys without duplicates. Previous editions and historical periods outside the requested interval remain stored. A failed request does not fall back to fixtures or another source.

Transport uses connection/read timeouts, bounded responses, strict JSON parsing, and bounded retries for transient connection errors, HTTP 429, and HTTP 5xx. Permanent HTTP errors fail immediately. The official API returned rate-limit responses during validation; operators should wait before retrying a rejected import rather than repeatedly requesting the provider. Failures are recorded in operational import history with sanitized public information.

## Verified source snapshot

For the default 24-country scope and 1960–2026 interval, the checked responses contain **800 government-debt observations across 23 countries** and **1,087 current-account observations across 24 countries**. Venezuela has no debt observations in this selected response; no zero-valued debt history is synthesized. Taiwan adds 30 government-debt and 43 current-account records through 2026 when requested explicitly. These counts describe the checked publication, not a permanent coverage guarantee.

The [recorded test fixtures](../../backend/src/test/resources/imf/README.md) preserve real metadata and a reduced set of actual response rows. Contract tests also exercise controlled malformed responses, exact precision, zero versus missing values, scope filtering, source failures, country mappings, metadata consistency, and release identity.
